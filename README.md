# SEEG-Propofol-Hippocampal-Analysis

Overview

This repository contains MATLAB scripts for analyzing intracranial stereoelectroencephalography (SEEG) recordings after propofol anesthesia.

The pipeline investigates hippocampal neural dynamics associated with early consciousness recovery after propofol anesthesia, including oscillatory activity, neural complexity, cross-frequency coupling, and high-frequency oscillations.

## Analyses included

- Power spectral density (PSD)
- Permutation entropy (PE)
- Phase-amplitude coupling (PAC/KLMI)
- Hippocampal ripple analysis
- Statistical analysis and visualization

## Data availability

Raw SEEG recordings are not publicly available due to patient privacy and ethical restrictions.

Analysis scripts are provided to facilitate reproducibility.

## Software requirements

MATLAB R2020b

Toolboxes:

- EEGLAB
- RIPPLELAB
